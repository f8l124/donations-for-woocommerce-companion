# v0.7.0 — Templates, bulk apply, diagnostics, WPML

The headline release. Solves admin-scale: a nonprofit with 50+ campaigns can now configure once and apply to many at a time.

## Highlights

### Layered config model

```
Defaults  →  Global Settings  →  Named Template  →  Campaign Overrides
                                                      (or Detached snapshot)
```

`Config_Resolver` merges all four layers at read time. Sequential arrays (presets) replace wholesale; associative arrays deep-merge. Detached campaigns get a frozen snapshot and ignore future template changes.

### Named templates + bulk apply

- **`WooCommerce → Donations Companion → Templates`** — create reusable configuration packages ("School Sponsorship", "Emergency Relief", "General Fund"). Each defines preset amounts, min/max, CTA template, custom-amount toggle, and display options for one-time / monthly / annual intervals.
- **Bulk actions on the campaign list** — apply a template to dozens of campaigns at once, reset Companion settings, or detach from template. Per-campaign capability check; surfaces applied-vs-skipped counts.
- **Override-aware save** — when you save a campaign, only fields you actually changed land in the override meta. Future template edits propagate normally to unchanged fields. Honest inheritance.

### Diagnostics page

- **`WooCommerce → Donations Companion → Diagnostics`** — 12 health checks covering WC, parent plugin, subscription engine, WPML/WCML, asset registration, hook contract.
- Status pills (pass / warning / fail), suggested remediations, copy-paste-ready Markdown support report (path-stripped, pipe-escaped, allow-listed context fields).
- Frontend gating — when contract is broken, the donor-side overlay falls back to parent's vanilla form rather than producing a half-broken UI.

### WPML integration (comprehensive)

- `wpml-config.xml` declares all custom fields and admin-text strings.
- Templates and campaign overrides register translatable strings with WPML String Translation under stable keys (`<template_id>.<interval>.<field>`).
- Strings translate at render time.
- Monolingual sites pay zero overhead.

### CI / QA hardening

Every PR now runs: PHPCS (WPCS) + PHPStan level 5 + PHPUnit + Plugin Check + parent-contract watcher + Playwright + zip-install validation. Release workflow auto-publishes the zip on tag push with a version-consistency check across the four canonical sources.

## Backward compatibility

Existing v0.6.x campaigns continue to render exactly as before. Legacy `_dfwc_companion_intervals` and `_dfwc_companion_display` meta is read by the resolver as a fallback layer; on the next admin save in v0.7.0+, the legacy keys migrate to `_dfwc_companion_overrides` automatically. Idempotent and per-campaign — no global migration sweep.

## Test coverage
