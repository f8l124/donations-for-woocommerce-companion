# v0.8.0 — Campaign taxonomies + donor-facing directory

Adds the missing nonprofit campaign-management layer for WooCommerce. Donors browse a filterable directory; admins classify campaigns by cause, region, country, and more.

## Highlights

### Six taxonomies on `wc-donation`

| Taxonomy | Slug | Hierarchical | Default terms |
|---|---|---|---|
| Cause Category | `dfwc_cause` | yes | Education, Discipleship, Medical, Food, Construction, Missions, Leadership Training |
| Region | `dfwc_region` | yes | (admin-driven) |
| Country | `dfwc_country` | no | (admin-driven) |
| Program | `dfwc_program` | no | (admin-driven) |
| Sponsorship Type | `dfwc_sponsorship_type` | no | School, Classroom, Student, Pastor, Teacher, Church, Missionary |
| Urgency | `dfwc_urgency` | no | Normal, Priority, Urgent |

Default terms seed once on first activation via the `dfwc_companion_terms_seeded` flag option. Admins can edit, delete, or extend freely thereafter — re-activations never re-seed. Filterable via `dfwc_companion_seeded_terms`.

### Three render surfaces for the directory grid

```
[dfwc_campaign_grid]
[dfwc_campaign_grid cause="education" country="kenya" featured="true" per_page="6"]
[dfwc_campaign_grid orderby="featured" layout="list"]
[dfwc_campaign_grid show_filters="false" lang="all"]
```

- **Shortcode** with cause / region / country / program / sponsorship_type / urgency / featured / s / orderby / order / per_page / layout / show_filters / lang attributes.
- **Gutenberg block** `dfwc-companion/campaign-grid` — server-rendered with InspectorControls for every attribute. Editor preview shows exactly what donors see.
- **Elementor widget** "Donation Campaign Grid" — registered alongside the existing recurring-donation widget.

### Live search via REST

`GET /wp-json/dfwc-companion/v1/grid?cause=...` returns rendered grid HTML. JS swaps the grid + count + pagination in place without full reload, then updates browser URL via `history.replaceState` so deep links work.

- Debounced search-as-you-type (300ms), immediate fetch on filter changes
- Falls back to full form submit if REST fails
- 60 req/min/IP rate limit (hashed-IP transient key — no PII stored)
- `show_filters=false` parameter prevents the filter bar re-rendering on every fetch (UI swap is just the grid)

### Featured campaigns

Side meta box on the campaign edit screen toggles featured status. `orderby="featured"` puts featured campaigns first using `meta_value_num` ordering with menu_order as tie-breaker. Featured cards get a "Featured" badge and a subtle border accent.

### WPML

Comprehensive support per `plans/v2/AA-wpml-integration.md`:
- All six taxonomies declared `translate="1"` in `wpml-config.xml` — WPML's Translation Management handles per-term translation natively. No companion code required.
- `_dfwc_companion_featured` meta declared `action="copy"`.
- WPML's `pre_get_posts` filter auto-scopes the query by current language.
- `lang="all"` shortcode/block/widget attribute overrides the default language scoping for cross-language directories.

## Backward compatibility

Existing v0.7.x campaigns continue to render unchanged. The new taxonomy meta boxes appear on the campaign edit screen but staying empty has no effect — campaigns without classifications show in the directory under "All", just without filterable metadata. No data migration required.
